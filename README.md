# Cristian Taccioli — personal website

Personal academic website for Cristian Taccioli, hosted with GitHub Pages.

The site presents research themes, selected open-source projects, teaching and links to the TACC Lab research group.

## Website

[tacc-code-tacclab.github.io](https://tacc-code-tacclab.github.io/)

## Structure

- `index.html` — page content and metadata
- `styles.css` — responsive visual design and colour themes
- `script.js` — theme switcher, mobile navigation and active-section state
- `favicon.svg` — site icon
