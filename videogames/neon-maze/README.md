# Neon Maze — Rift Runner

An original neon maze-chase arcade game connected visually to Rift Rush while using its own procedural maze, characters and progression systems.

- Continuous held-arrow controls; swipe and four-button D-pad on touch devices.
- Deterministic daily maze with looped corridors and side portals.
- Four independently moving Echoes with different chase behaviours.
- Rift Shard chains, automatic Overdrive, power cores, bonuses and endless level progression.
- Three persistent cosmetic runner colours unlocked through score milestones.
- Lightweight Canvas 2D vector rendering, sound effects and a procedural neon soundtrack; no external assets or libraries.
- Persistent local best and daily best scores.

The implementation blocks browser zoom, overscroll and accidental page gestures during play.
