# The Northern Kthulu and the Silent Vessel — version 10

Self-contained build (`index.html`). Version 9 stays at `../northern-kthulu/`.

New in 10: a fully fitted bridge with signs in the player's language, explanations on every used lever and console,
Kthulu remodelled after the old description, a thunderstorm and lightning on the ship when it rises, and the Writer's name.

Languages: Italiano (default), English, Español, Français, Deutsch — Settings → Language.
PC: WASD · mouse · left mouse / R / Q / Enter fire · T reload · C crouch (X toggles) · Space jump · E use · 1–7 weapons.
Phone / tablet: landscape, left thumb moves, right thumb looks, on-screen buttons.
