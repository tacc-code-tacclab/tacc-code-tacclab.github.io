# Totem Balance

An original touch-first browser physics game. Players alternate with the Oracle, hooking asymmetrical forged relics onto an ancient vertical totem. The player who collapses the structure loses the round.

## Controls

- Drag a relic by its glowing hook.
- Rotate with the on-screen arrows, mouse wheel, or keyboard arrows.
- Change the active attachment point with **Hook** or `Tab`.
- Release near a golden joint or press **Place**.

The game is dependency-free and designed for desktop and mobile browsers.
