# Roblox Studio edition

1. Download `Bertranda.rbxlx`.
2. Open Roblox Studio and choose **File → Open from File…**.
3. Select the downloaded file.
4. Press **Play**. The server script builds the boarding house, five nests, hiding wardrobes, exit and Bertranda at runtime.
5. To publish it to your Roblox account, use **File → Publish to Roblox As…**.

Controls are Roblox-standard first-person movement. Hold `Shift` to run, press `F` for the torch, and use the on-screen buttons on mobile. Proximity prompts handle nests, wardrobes and the exit.

The file is intentionally self-contained and uses no third-party models, meshes, textures, music or paid assets.
