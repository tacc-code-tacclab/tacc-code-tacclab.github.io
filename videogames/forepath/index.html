Read the full debrief

This pilot examines whether choices or pre-outcome ratings differ from chance when the outcome is assigned after the response. Some feedback was deliberately hidden to create a control condition.

The design cannot diagnose telepathy or prove a paranormal ability in one person. Expectation, response habits, technical timing and multiple testing can all create misleading patterns, so confirmatory conclusions require ethics approval, preregistration, a fixed analysis plan and independent replication.
