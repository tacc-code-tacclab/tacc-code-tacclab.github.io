# Rift Rush — Neon Hunters

An original two-minute 2D survivor roguelite designed for immediate desktop and one-thumb mobile play.

- Auto-aim combat, direct movement and a dedicated dash.
- Three hunters with distinct starting stats.
- Escalating enemy waves, combo scoring, experience shards and random upgrade choices.
- A final Rift Titan boss and persistent local best score.
- Procedural vector art with no external image dependencies.
- Fixed mobile viewport with pinch, double-tap zoom, page drag and overscroll suppression.

Controls: WASD/arrow keys plus Space on desktop; analogue thumb stick plus DASH on touch devices.
