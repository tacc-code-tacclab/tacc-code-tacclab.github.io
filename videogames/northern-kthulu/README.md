# The Northern Kthulu and the Silent Vessel

Browser 3D first-person survival-horror shooter (three.js, WebGL 2). `index.html` is a self-contained build:
geometry, textures, creatures and sound are all generated in code.

Controls: WASD move · mouse look · Shift sprint · C crouch · left mouse fire · R reload · 1/2 weapons ·
E interact · F flashlight · H medkit · Tab journal · Esc/P pause. Desktop keyboard and mouse only.
