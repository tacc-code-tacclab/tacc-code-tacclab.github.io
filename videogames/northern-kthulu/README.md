# The Northern Kthulu and the Silent Vessel

Browser 3D first-person survival-horror shooter (three.js, WebGL 2). `index.html` is a self-contained build (version 8):
geometry, textures, creatures and sound are all generated in code.

Languages: Italiano (default), English, Español, Français, Deutsch — Settings → Language.

PC: WASD move · mouse look · Shift sprint · Space jump · C crouch (X toggles) · left mouse / R / Q / Enter fire · T reload · 1–7 / wheel weapons ·
E interact · F flashlight · H medkit · Tab journal · Esc/P pause.

Phone / tablet (landscape): left thumb moves, right thumb looks, on-screen buttons for everything else.

On a phone the game asks for full screen at the first tap. On iPhone use Share → Add to Home Screen and start it from the icon.
